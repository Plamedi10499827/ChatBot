# Cybersecurity Awareness Chatbot

## 1. Overview

The Cybersecurity Awareness Chatbot is a C# Windows Forms application designed to help users learn about cybersecurity and online safety. The chatbot allows users to enter messages and receive responses about common cybersecurity topics.

The application includes a graphical user interface (GUI), a cybersecurity logo, a recorded voice greeting, and a chatbot engine that processes user input and generates responses.

## 2. Technologies Used

- **C#** – The programming language used to develop the application.
- **.NET 8** – The framework used to run the application.
- **Windows Forms** – Used to create the graphical user interface.
- **System.Media.SoundPlayer** – Used to play the recorded voice greeting.
- **System.IO** – Used to locate the image and audio files.
- **ChatEngine class** – Processes user input and generates chatbot responses.

## 3. How the Code Works

### Program.cs

The `Program.cs` file is the entry point of the application. It starts the Windows Forms application and opens the main form where the chatbot interface is displayed.

### Form1.cs

The `Form1.cs` file controls the chatbot's graphical user interface and manages user interactions.

Its main functions include:

- Displaying the cybersecurity logo when the application opens.
- Playing the recorded voice greeting.
- Displaying welcome messages and prompting the user to enter their name.
- Accepting messages entered by the user.
- Sending user messages to the chatbot engine.
- Displaying the user's messages and the chatbot's responses.
- Allowing the user to send messages using the Send button or the Enter key.
- Allowing the voice greeting to be played again.
- Releasing audio and image resources when the form closes.

The code checks whether the image and audio files exist in the application's output directory before attempting to load them.

### ChatEngine.cs

The `ChatEngine.cs` file contains the chatbot's response logic. It processes the user's input and determines an appropriate response.

Its functions include:

- **Keyword recognition:** Identifies cybersecurity topics such as passwords, phishing, scams, privacy, malware, hacking, Wi-Fi security, backups, software updates, and social engineering.
- **Random responses:** Selects from predefined responses for supported topics.
- **Conversation flow:** Handles greetings, thanks, help requests, and follow-up questions.
- **Name memory:** Stores the user's name so the chatbot can refer to the user during the conversation.
- **Favourite topic memory:** Stores a supported cybersecurity topic when the user identifies a favourite topic.
- **Sentiment detection:** Recognises certain expressions indicating that the user may be worried, confused, or frustrated and provides an appropriate response.
- **Input processing:** Normalises user input and checks for recognised keywords and phrases.

If the chatbot cannot identify a supported topic, its response logic determines how to handle the input.

### Form1.Designer.cs

The `Form1.Designer.cs` file contains the code generated by Windows Forms Designer. It defines the form's controls and layout, including the picture boxes, conversation display, input field, and buttons.

It also connects controls to their event handlers, allowing the interface to respond to actions such as clicking a button or pressing Enter.

### ChatBot.csproj

The `ChatBot.csproj` file contains the project configuration. It specifies the .NET target framework, enables Windows Forms, and configures the image and audio files to be copied to the output directory when the project is built.

This allows the application to locate the required resources when it runs.

## 4. Image and Audio Files

The application uses the following resources:

- `images/Bope0401.JPG` – The cybersecurity logo displayed in the interface.
- `voice/Bope_recording.wav` – The recorded voice greeting played when the application starts or when the user selects the audio replay button.

The application locates these files relative to its output directory rather than relying on a fixed computer-specific file path.

## 5. Application Workflow

1. The application starts and opens the main form.
2. The cybersecurity logo is loaded and displayed.
3. The recorded voice greeting is played.
4. A welcome message is displayed, and the user is prompted to enter their name.
5. The user enters a message in the input field.
6. The message is passed to `ChatEngine.cs` for processing.
7. The chatbot checks the input for recognised topics, conversation commands, memory-related information, or sentiment indicators.
8. The chatbot generates a response and displays it in the conversation area.
9. The user can continue sending messages or replay the voice greeting.
10. When the application closes, the audio player and image resources are released.

## 6. Conclusion

The Cybersecurity Awareness Chatbot uses separate classes to manage the interface, chatbot logic, and application configuration. This structure makes the code easier to understand, maintain, and update. The application combines a Windows Forms interface with keyword recognition, predefined responses, conversation handling, memory, sentiment detection, and audio and image resources to provide a basic cybersecurity learning experience.
